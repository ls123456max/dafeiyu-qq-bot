# 费用：到底一天要花多少钱

先说结论：**纯文字聊天，一天 0.1–1 元**。真正把账吹起来的不是「聊得多」，而是「每轮带多少上下文」和「语音/视频/搜索」。

## 1. 钱花在哪

| 项目 | 是否花钱 | 说明 |
|---|---|---|
| 人格文件 / 表情包 / fish-soul 插件 | 否 | 开源，MIT |
| QQ 通道（NapCat） | 否 | 但你得有个能一直开着的机器 |
| 模型 API | **是** | 唯一的主要开销 |
| 语音合成（Edge TTS） | 否 | 本机免费；云端 TTS 按分钟计费 |
| 抖音浏览 | 基本否 | 只是额外的模型调用 |
| 搜图 / 联网搜索 | 少量 | 每次搜索 = 一次额外请求 |

## 2. 模型单价（2026-11 官方牌价，元 / 百万 token）

DeepSeek：

| 模型 | 输入(缓存命中) | 输入(未命中) | 输出 |
|---|---|---|---|
| deepseek-flash | 0.02（空闲）/ 0.04（高峰） | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.30 | 4.5 / 9 | 13.5 / 27 |

- 高峰 = 周一至周五 9:00–12:00、14:00–18:00（北京时间），其余时间半价。
- 智谱 GLM（新用户赠额度）：`glm-5.3-flash` 等按 token 计费，赠送额度用完前为 0 元。

> 不同厂商计费口径不同，接入前请以官方价目页为准。

## 3. 一轮对话的成本怎么算

一轮 = 输入 token × 输入单价 + 输出 token × 输出单价。

**关键：每轮都要把「系统提示 + 全部历史」重新发一遍。** 所以第 50 轮和第 1 轮的成本差 50 倍。

实测（大肥鱼人格 + 7 个工具 + DSK 系统提示）：

| 会话里的第几轮 | 输入 token | 单轮成本（deepseek-flash，缓存命中） |
|---|---|---|
| 第 1 轮 | ≈ 4.2k | ≈ 0.0002 元 |
| 第 10 轮 | ≈ 17k | ≈ 0.0006 元 |
| 第 20 轮 | ≈ 38.5k | ≈ 0.0013 元 |
| 第 30 轮 | ≈ 59k | ≈ 0.0020 元 |
| 第 38 轮 | ≈ 76k | ≈ 0.0026 元 |

一个聊到 3.8 万 token 的会话，累计已烧掉约 **156 万 token**。

## 4. 一天多少钱

按每天 50 轮（私聊 + 群聊合计）估：

| 场景 | 每轮平均 | 一天 | 一个月 |
|---|---|---|---|
| 每天换会话（推荐） | ≈ 0.002 元 | **≈ 0.1 元** | ≈ 3 元 |
| 一直不换会话 | ≈ 0.005 元 | ≈ 0.25 元 | ≈ 8 元 |
| 开语音（云端 TTS） | + 0.1–1 元/条 | 1–10 元 | 30–300 元 |

100 轮/天大致 0.2–0.5 元/天；400 轮/天（群聊很活跃）1–2 元/天。

## 5. 赠送额度能撑多久

以智谱 2000 万 tokens 为例：

- 不换会话：约 450 轮 ≈ 9 天（50 轮/天）
- 每天 05:00 换会话：约 780 轮 ≈ 15 天

## 6. 省钱清单（按收益排序）

1. **每天换会话**：`scripts/session/rotate_session.py`，装成 05:00 的计划任务。省一半以上。
2. **用带缓存折扣的模型**：同一段上下文，缓存命中比未命中便宜 50 倍。
3. **别把工具和系统提示堆太满**：工具定义也是每轮重发的。
4. **关掉思考/推理档位**（如果模型支持）：输出 token 省 5 倍左右。
5. **语音默认关**，只在点名要的时候发。
6. **群聊白名单**：不相关的群别放进来。
7. **搜索按需**：她只在遇到实时信息时搜，闲聊不搜。
8. **第三方中转要谨慎**：不少中转不吃缓存，单价看着便宜，实际更贵。

## 7. 怎么核对真实花费

- DeepSeek 控制台 → 用量统计（按天、按模型）
- 本机 `~/.dsh/.dshw-usage.json`：只有「上次余额」和「今日差额」，够看趋势
- 想看逐轮 token：DSH 会话文件是 zstd 多帧压缩的，需要 `read_across_frames=True` 才能完整解压
